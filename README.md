# Cambridge Students Chinese

一个为剑桥国际课程（Cambridge IGCSE）中文学习者打造的实用工具集合项目，旨在辅助学习、教学与成绩分析。

---

## 项目简介

本项目目前包含两个核心工具：

1. **Cambridge Students Chinese 成语词典工具**
2. **Cambridge Students Chinese 中文第一语言成绩计算器**

两个工具相互独立、并列使用，既服务日常学习，也支持考试成绩分析。

---

## Cambridge Students Chinese 成语词典工具

### 功能简介
- 成语查询：支持成语及释义的全文搜索
- 成语释义：展示直译与意译，帮助学生理解含义
- 成语故事：收录部分成语的历史典故与文化背景
- 成语挑战：提供成语答题竞猜功能，提升学习积极性
- 随机推荐：提供随机成语与成语故事，辅助日常学习
- 响应式设计：支持桌面与移动端访问，基于 Bootstrap 5 构建

---

### 技术栈

- 前端: HTML5, CSS3, JavaScript (ES6+)
- 框架: Bootstrap 5
- 数据源: 成语 JSON 数据集（包含释义与故事）

---

## Cambridge Students Chinese 中文第一语言成绩计算器

### 功能简介

- 输入 Paper 1 和 Paper 2 分数
- 自动计算：
  - 总分（Raw Score）
  - 100分制成绩
  - 120分制成绩（加权）
  - 对应等级（A* – G）
- 支持不同年份的等级边界（Grade Thresholds）

### 技术栈

- 使用 HTML + CSS + JavaScript
- 基于 Bootstrap 构建响应式界面
- 蓝色简约主题设计
- 无需后端，纯前端运行
